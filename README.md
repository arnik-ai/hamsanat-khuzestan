# هم‌صنعت خوزستان — نسخه نمایشی

نمونه اولیه تعاملی «درگاه هوشمند خدمات و توسعه کسب‌وکارهای صنعتی» برای ارائه به شرکت شهرک‌های صنعتی خوزستان.
همه داده‌ها فرضی‌اند. بک‌اند، API، ورود واقعی و سرویس خارجی ندارد و بدون اینترنت کار می‌کند.

## اجرا
- `index.html` را با دوبار کلیک در Chrome یا Edge باز کنید.
- برای ارسال به دیگران: `hamsanat-khuzestan-demo.html` (یک فایل که فونت و کد داخل آن است).
  بعد از هر تغییر در کد، این فایل را دوباره بسازید: `node tools/build-single.js`
- تغییرات در مرورگر (localStorage) می‌ماند؛ برای شروع دوباره: منوی کاربر ← «بازنشانی داده‌های دمو».

## سناریوی پیشنهادی ارائه
1. داشبورد ← «گزارش مشکل» ← ثبت پرونده (کد پیگیری می‌گیرد).
2. «ورود به‌عنوان کارشناس شهرک» ← باز کردن همان پرونده ← تغییر وضعیت + یادداشت داخلی + تعیین مسئول.
3. «ورود به‌عنوان شرکت» ← زنگ اعلان ← وضعیت تازه و تاریخچه پرونده؛ یادداشت داخلی برای شرکت دیده نمی‌شود.
4. «ثبت نیاز جدید» ← پیشنهادهای مرتبط همراه با دلیل تطبیق (قواعد ساده، نه هوش مصنوعی).
5. صادرات ← انتخاب بازار ← ارزیابی اولیه ← چک‌لیست اقدامات ← ارسال برای کارشناس.

اگر دو پنجره باز کنید (یکی به‌عنوان شرکت و یکی به‌عنوان کارشناس شهرک)، تغییرات هر پنجره در دیگری هم دیده می‌شود.

## ساختار کد
| فایل | کار |
|---|---|
| `assets/data.js` | داده‌های نمایشی و ثابت‌ها (دسته‌ها، وضعیت‌ها، بازارها) |
| `assets/core.js` | state و ذخیره، مسیریابی، پنجره‌ها، فرم‌ها، قواعد تطبیق و پیگیری |
| `assets/page-*.js` | هر صفحه: داشبورد، نیازها، صادرات، میز خدمت و پنل کارشناس، سایر بخش‌ها |
| `assets/main.js` | اتصال رویدادها، جست‌وجوی سراسری، شروع برنامه |
| `assets/base.css`، `assets/pages.css` | استایل‌ها |
| `assets/font.css` | فونت وزیرمتن (مجوز OFL) به‌صورت درون‌فایلی |
